# ルール v1

採用日: 2026-09-07

## 売買ルール

| | 値 |
|---|---|
| 損切り | -8% |
| 利確 | +22% |
| 必要勝率（日本株） | 26.7% |
| 必要勝率（米国株、往復1%） | 30.0% |

**出典:** William O'Neil『How to Make Money in Stocks』（CAN SLIM）

**根拠:** IBDによる調査で、適切な買い場で買った勝ち銘柄が7-8%以上下げることは稀。
それを超えたら想定が外れた統計的サインとする。利益側は、勝ち銘柄の最初の大きな
上昇が20-25%で一旦止まることが多いという調査結果に基づく。本システムでは
その範囲の中で **+22% を固定値として採用**しており、+20〜25%のどこかを
都度選ぶわけではない（`entry_price` に対して常に ×1.22 / ×0.92 で計算する）。

必要勝率は、損切り -8% ・利確 +22% ・上記の手数料率を
`investment.sizing.required_win_rate` に代入した実測値であり、丸めや
概算ではない（日本株: 0.08 / (0.22 + 0.08) = 0.2667、米国株は往復1%の
手数料を利益側・損失側それぞれに加味して 0.09 / (0.21 + 0.09) = 0.30）。
利確幅や損切り幅を変更した場合、この必要勝率もあわせて再計算すること。

## スクリーニング条件

| | 値 |
|---|---|
| 時価総額 | 300億円以下 |
| 売上高増減率 | 20%以上 |
| 営業利益率 | 10%以上 |
| ROE | 15%以上 |
| 自己資本比率 | 40%以上 |

**出典:** Instagram投稿 hide._money（日本株歴40年）2026-07-29

**根拠:** CAN SLIM の C/A/S/L とほぼ一致する。独立した2つの出典が同じ結論に
到達していることを採用理由とする。

## 変更時の手順

設計書 16章に従う。サンプルが30件未満の段階での変更は、成績ではなく運を
見ている可能性が高い。
