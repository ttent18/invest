# ルール v3

採用日: 2026-09-07（v2 と同日）

**v2 からの変更点: 4つの枠を「じっくり枠」「回転枠」に2つずつ分けた。**
売買ルール（v2 の +22%/-8%）は「じっくり枠」としてそのまま残る。

## なぜ変えたか

**成績を見て変えたのではない。どちらの型が向いているかを測るために、
2つを並行して走らせることにした。**

v2 までは全4枠が同じルール（+22%/-8%、想定6週間）だった。しかし
「もっと短いスパンで回したい」という要望があり、どちらが良いかを
議論で決める材料が無かった。**勝率の実測が1件も無いため。**

議論で決められないものは、両方走らせて測る。同じ資金・同じ枠数で
並行させれば、半年ほどで勝率を比較できる。

**あわせて、利確幅・損切り幅がルールどおりかを機械的に検証するようにした。**
v1・v2 では、AIが「+22%と書け」と指示されていても +15% と書けば
そのまま通っていた（幅の検証が一度も入っていなかった）。枠を分ける以上、
ここを塞がないと「枠」が名前だけのラベルになり、比較そのものが成立しない。
検証に使う幅は `src/investment/config.py` の `BUCKETS` から取る。
AIが書き換えられるファイル（`build/context.json`）の値は使わない。

## 2つの枠

| | じっくり枠 | 回転枠 |
|---|---|---|
| 枠数 | 2 | 2 |
| 利確 | +22% | **+10%** |
| 損切り | -8% | **-5%** |
| 損益トントンの勝率 | 26.7% | **33.3%** |
| 想定保有期間 | 6週間前後 | **2週間前後** |
| 期限 | なし | **10営業日** |
| 1銘柄の金額 | 137,500円（総資金の25%）| 同じ |

1銘柄あたりの金額は両方とも同じ。**変えるのは「どこで降りるか」だけ**にして、
比較から余計な変数を減らしている。

### 回転枠に期限を付けた理由

**利確にも損切りにも当たらない銘柄が、枠に居座り続けるのを防ぐため。**

同時に持てるのは4枠しかない。1件が居座ると使える枠が25%減り、
そのまま戻らない。回転枠は「2週間で結論が出る」という前提で入るので、
**10営業日たって結論が出ていなければ、その前提自体が外れている。**
勝ち負けに関係なく降りて枠を空ける。

じっくり枠に期限を付けていないのは、そちらの根拠が「次の決算で数字が出る」
であり、決算日という外部の期日が決着をつけるため。ただし
**じっくり枠にも同じ居座りの問題はあり、未解決である。**
実際の値動きの速さを見てから判断する。

### 必要勝率が上がることの意味

回転枠は利確を +22% → +10% に狭めるので、**損益トントンの勝率が
26.7% → 33.3% に上がる。** 「+22%まで待てば取れたはずの値幅」を
捨てるぶん、多く当てないと釣り合わない。回転が速いことは、
勝率が同じなら有利だが、勝率が下がれば不利になる。**どちらが起きるかは
まだ分からない。それを測るのがこの版の目的である。**

## 期待値の見積り（2026-09-07 時点の試算）

「損益トントンの勝率より10%ポイント多く勝てたら」という共通の仮定での比較。
**これは希望であって予測ではない。実績は0件。**

| 配分 | 年間取引数 | 年間の伸び | 回転枠の腕がゼロなら |
|---|---|---|---|
| じっくり3 / 回転1 | 52回 | +29.3% | +19.5% |
| **じっくり2 / 回転2（採用）** | **69回** | **+32.5%** | **+13.0%** |
| じっくり1 / 回転3 | 87回 | +35.8% | +6.5% |

2:2 を選んだ理由は期待値ではなく、**同じ資金・同じ枠数で公平に比較できること。**
回転枠は年52回、じっくり枠は年17回の取引になるため、回転枠のほうが
早くデータが溜まる。配分を動かすのは実測が出てからにする。

## 売買ルール（じっくり枠の根拠は v2 から変更なし）

**出典:** William O'Neil『How to Make Money in Stocks』（CAN SLIM）。
+22%/-8% の根拠は [v1.md](v1.md) を参照。

**回転枠の +10%/-5% には、v1・v2 のような外部の出典が無い。**
「じっくり枠のちょうど半分弱の値幅で、リスクリワード比 2:1 を保つ」という
設計上の選択である。出典の無い数字なので、**実測が出たら真っ先に見直す対象**。

## スクリーニング条件（v2 から変更なし）

| | 値 |
|---|---|
| 時価総額 | 300億円以下 |
| 売上高増減率（直近四半期の前年同期比） | 20%以上 |
| 営業利益率 | 10%以上 |
| ROE | 15%以上 |
| 自己資本比率 | 40%以上 |

売上高増減率が四半期の数字であることの説明は [v2.md](v2.md) を参照。

## 単元・S株（v2 から変更なし）

日本株は100株単位。S株（単元未満株）は逆指値が使えないため使わない。
詳細は [v2.md](v2.md) を参照。

## 変更時の手順

設計書 16章に従う。サンプルが30件未満の段階での**成績に基づく**変更は、
成績ではなく運を見ている可能性が高い。この版は成績に基づく変更ではなく、
**成績を測るための版である。**

**次に見直すタイミング:** 各枠の決着が15件ずつ溜まったとき。
そこで勝率・平均保有日数・期限切れの件数を比較する。
