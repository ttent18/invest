# ルール v2

採用日: 2026-09-07（v1 と同日）

**v1 からの変更点: 1銘柄に投じる上限を 15% → 25%、同時保有を 5銘柄 → 4銘柄。**

## なぜ変えたか

**成績を見て変えたのではない。v1 のルールでは実際には発注できないことが
分かったため、その修正である。** 設計書16章は「サンプル30件未満での変更は
運を見ている可能性が高い」と警告しているが、これは成績に基づく変更への
警告であり、実行不能なルールの修正はそれに当たらない。

### 何が起きたか

日本株は通常 **100株をひとまとまり（単元）** としてしか売買できない。
v1 の1銘柄上限は 550,000円 × 15% = **82,500円** だった。

→ **100株買って82,500円に収まる株価の上限は825円。**
   それより高い銘柄は1株も買えない。

2026-09-07 の初回運用で、スクリーニングを通った41銘柄の株価は
中央値1,318円・最高4,055円で、**82,500円以内で100株買えるのは9件だけ**
だった。AI が選んだ2銘柄（3723.T 2,704円 / 4058.T 2,329円）は
100株でそれぞれ270,400円・232,900円になり、**どちらも発注できなかった。**

### なぜ 25% なのか

| 1銘柄上限 | 金額 | 100株で買える候補（41件中） |
|---|---|---|
| 15%（v1） | 82,500円 | 9件 |
| **25%（v2）** | **137,500円** | **22件** |
| 33% | 183,333円 | 27件 |
| 50% | 275,000円 | 36件 |

25% を選んだ決め手は件数ではなく、**既存のリスクルールとちょうど一致すること**。

```
137,500円 × 損切り8% = 11,000円 = 総資金550,000円 の 2.0%
                                   ↑ risk_per_trade_pct と完全に一致
```

v1 の15%では1回の損失が6,600円＝1.2%にしかならず、**「1回の損失は資金の2%まで」
と宣言しておきながら、その半分強しか使っていなかった。** 25%にすると
「1銘柄の金額上限」と「1回の損失上限」が同じ点で効くようになり、
2つのルールが矛盾しなくなる。

同時保有を4銘柄にしたのは、25% × 4 = 100% で資金がちょうど使い切れるため。
5銘柄のままだと、5枠目は制度上ありえない枠になる。

なお4銘柄目まで資金が届くのは、**株数を単元に切り下げる際に必ず切り捨てる**
ためで、実際の投入額は毎回25%以下になる。ただし現時点で「現金残高が足りるか」
を確認する処理はどこにも無く、4枠が埋まるのは計算上そうなるというだけである
（購入を記録する仕組みができた段階で、残高の確認を入れる必要がある）。

## 単元未満株（S株）を使わない理由

SBI証券には1株から買える「S株」があるが、**使わない。**

> 「成行注文のみとなります。指値注文はできません。」
> 約定は1日1回（昼間取引=前場終値、夜間取引=翌9:00始値）
> — [SBI証券 S株（単元未満株）取引ルール](https://search.sbisec.co.jp/v2/popwin/attention/trading/stock_07.html)

（「前場」は午前の取引時間のこと。日本の株式市場は午前と午後に分かれており、
午前が9:00〜11:30、午後が12:30〜15:30。「前場終値」は11:30時点の値段を指す。）

指値が出せないということは、**「この値段まで下がったら売る」という逆指値も
出せない**ということ。このシステムは損切りを証券会社側の逆指値に任せる設計
（利用者は日中も夜も画面を見ない前提）なので、S株を使うと**損切りそのものが
機能しなくなる。** 単元未満で買えることより、損切りが自動で効くことを優先する。

| | 値 |

| 自己資本比率 | 40%以上 |

### 売上高増減率が何を指すか（v2 で明文化）

**この値は「直近の四半期（3ヶ月）を、前年の同じ四半期と比べた伸び」である。
年間の伸びではない。** データ提供元 yfinance の `revenueGrowth` をそのまま
使っている。

v1 ではこれを書いていなかったため、2026-09-07 の初回運用で AI が年間の
決算数字と突き合わせ、「データが壊れている」と判断してしまった。実測:

| 銘柄 | 表示値（四半期の前年同期比） | 直近年間の増収率 |
|---|---|---|
| 5885.T ジーデップ | +92.3% | +4.8% |
| 3723.T ファルコム | +53.2% | +3.5% |

**どちらの数字も正しく、測っている期間が違うだけである。**

これは CAN SLIM の "C"（直近四半期の急成長）に対応する指標であり、
指標として誤ってはいない。ただし "A"（年間の継続成長）は見ていないため、
**「1四半期だけ跳ねた銘柄」が上位に来る性質がある。** 数ヶ月で+22%を狙う
本ルールとは相性が良いとも言えるが、この性質を承知のうえで使うこと。
年間の伸びも条件に加えるかは、運用データが溜まってから判断する。

**出典:** Instagram投稿 hide._money（日本株歴40年）2026-07-29。
CAN SLIM の C/A/S/L との一致については [v1.md](v1.md) を参照。

## 変更時の手順

設計書 16章に従う。サンプルが30件未満の段階での**成績に基づく**変更は、
成績ではなく運を見ている可能性が高い。実行不能なルールの修正はこれに当たらない。
