# 計画2-B: スマホの画面 — 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** iPhoneのホーム画面のアイコンから、今日買うべきものを見て、買った/売ったを数タップで記録し、保有と収支を確認でき、動くべきときだけ通知が届く状態にする。

**Architecture:** Cloudflare Pages に静的な画面を置き、同じ場所で動く Pages Functions が秘密情報を保持して Neon と GitHub Actions を仲介する。**Functions は計算しない** — `fills` テーブルへの追記と読み取りのSQLだけを行う。保有・現金・履歴の計算は計画2-A で作った Python が行う。

**Tech Stack:** Cloudflare Pages / Pages Functions / `@neondatabase/serverless`（HTTP経由でNeonに接続）/ 素のHTML+CSS+JavaScript（フレームワーク無し）/ vitest / Service Worker / Web Push

**Spec:** [docs/superpowers/specs/2026-09-07-pwa-design.md](../specs/2026-09-07-pwa-design.md)

**前提:** 計画2-A（[2026-09-07-plan2a-recording-loop.md](2026-09-07-plan2a-recording-loop.md)）が main にマージ済み。`fills` / `push_subscriptions` テーブル、`db.select_bucket_performance` / `select_capital` / `select_positions` / `select_cash` / `select_unapplied_fills`、`investment.jobs.apply_fills`、`investment.notify.send` が存在する。

## Global Constraints

- **投資用語を説明なしに使わない。** 利用者は投資初心者。画面の文言・コメント・通知・ドキュメントの日本語は、専門家でない人が読んで分かる言葉で書く。英語の識別子はそのままでよい
- **Functions は計算しない。** 保有株数・平均取得単価・現金の増減を JavaScript で計算しない。`fills` に1行入れるだけ。計算は Python（`investment.fills` / `investment.jobs.apply_fills`）だけが行う
- **Functions が書き込んでよい表は3つだけ:** `fills` / `push_subscriptions` / `proposals.outcome`。`positions` / `cash` / `trades` には一切書かない
- **枠ごとの成績を JavaScript で計算し直さない。** `db.select_bucket_performance` と同じSQLで取り、そのまま返す
- **画面のJavaScriptに秘密を置かない。** ブラウザに配るものは全部見えると考える。例外は VAPID の公開鍵（公開前提）
- **データを黙って落とさない。** 反映できていない記録は画面の一番上に出す
- **損切り価格を最も目立たせる。** この仕組みの安全装置はSBI側の逆指値（この値段まで下がったら売る予約注文）であり、入れ忘れると全部が崩れる
- **株価は15〜20分遅れ。** 「いつ時点の値か」を必ず添える。リアルタイムに見せかけない
- 枠は `じっくり`（利確 +22% / 損切り -8% / 2枠 / 期限なし）と `回転`（利確 +10% / 損切り -5% / 2枠 / 期限10営業日）
- **iPhoneはホーム画面に追加しないと通知が来ない。** タブで開かれていることを検知して案内を出す
- ruff の設定に従う（Python側）。`import` はファイル冒頭にまとめる
- コミットメッセージは日本語。末尾に `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>` を付ける

## 技術上の決定（実装前に確定させたもの）

**Neon への接続は `@neondatabase/serverless`（HTTP経由）を使う。Hyperdrive は使わない。**
Cloudflare は Hyperdrive（接続を束ね直す別サービス）＋通常のドライバを推奨しているが、
その利点は1日数回しか叩かないこのシステムでは効かない。一方 Hyperdrive は Cloudflare 側に
追加のリソースと結び付けの設定が必要になる。**利用者が設定する項目を1つ減らすほうが価値がある。**

**フレームワークを使わない。** 画面は3つ、状態は「サーバーから取ってきたJSON1つ」しかない。
React 等を入れるとビルド設定・依存関係・バージョンの管理が増え、利用者が自分の仕組みを
読めなくなる。素のHTML+CSS+JavaScriptで足りる。ビルド工程も無い。

**テストの範囲。** Functions の純粋な部分（入力の検証、返す形の組み立て）は vitest で
テストする。SQL は Python 側の統合テストと同じ表・同じ列を使うため、**SQLそのものの検証は
Python 側に任せる**（二重に書かない）。画面（HTML/JavaScript）は自動テストを書かず、
デプロイして実機で確認する。個人用の画面3つに対してブラウザの自動テスト基盤を組むのは、
得るものより手間が大きい。**この判断は意図的であり、実機確認を手順書に明記する。**

```python
def save_last_prices(conn, prices: dict[str, float]) -> int:
    """最後に見た株価を保有に保存する。戻り値は更新した件数。

    渡された銘柄だけを更新する。取れなかった銘柄の古い値は消さない。
    古い値でも「いつ時点か」を添えれば画面に出せるが、消すと何も出せなくなる。
    """
    if not prices:
        return 0
    with conn.cursor() as cur:
        cur.executemany(
            """
            UPDATE positions
            SET last_price = %s, last_price_at = NOW()
            WHERE symbol = %s
            """,
            [(price, symbol) for symbol, price in prices.items()],
        )
        updated = cur.rowcount
    conn.commit()
    return updated
```

- [ ] **Step 5: `morning_check.run()` から呼ぶ**

`run()` の中で、`fetch_range` が成功した銘柄の**終値にあたる値**を集めて、最後に `save_last_prices` を呼ぶ。

`fetch_range` は `(高値, 安値)` を返すため終値そのものは無い。**その2つの中間ではなく、
`fetch_last_price` を使わずに済ませるため、高値と安値の平均を使わないこと。**
代わりに `investment.market.fetch_last_price(symbol)` を1回呼んで終値を取る。

    try:

### `sw.js`（Service Worker）

```javascript
// 通知を受け取って表示する。
// 送られてくる中身は investment/notify.py が作る
// { "title": "…", "body": "…", "url": "/" }

self.addEventListener("push", (event) => {
  const data = event.data ? event.data.json() : {};
  event.waitUntil(
    self.registration.showNotification(data.title || "投資", {
      body: data.body || "",
      icon: "/icon-192.png",
      data: { url: data.url || "/" },
    })
  );
});

self.addEventListener("notificationclick", (event) => {
  event.notification.close();
  const url = event.notification.data?.url || "/";
  event.waitUntil(clients.openWindow(url));
});
```

1. `Notification.requestPermission()` で許可を求める（**必ず押されたことをきっかけに呼ぶ**。

2. 許可されたら `registration.pushManager.subscribe({ userVisibleOnly: true,

### 書き方の指針

**読む人は投資にもWebにも詳しくない。** 次を守ること。

- **画面のどのボタンを押すか**まで書く（「Settings → Environment variables → Add variable」）
- **入力する値は表にする**（名前と値の対応が一目で分かるように）
- **なぜそうするのかを1行添える**（「ビルドコマンドを空にするのは、変換するものが無いから」）
- **やってはいけないことは、なぜダメかも書く**（「出力ディレクトリを空や `/` にすると
  リポジトリ全体が公開対象になる」）
- **専門用語には説明を添える**（「逆指値（この値段まで下がったら売る予約注文）」）

### 含める内容

**1. GitHubのトークンを作る**
- Settings → Developer settings → Personal access tokens → Fine-grained tokens
- Repository access: **このリポジトリのみ**
- Permissions: **Actions を Read and write** だけ。他は付けない
- Expiration: 期限を設定する
- **なぜ:** 画面の「いま分析して」ボタンが GitHub を動かすため。
  権限を絞るのは、漏れたときの被害を小さくするため

**2. Cloudflare Pages のプロジェクトを作る**

| 項目 | 値 |
|---|---|
| リポジトリ | `ttent18/invest` |
| Production branch | **`main`** |
| フレームワーク プリセット | なし |
| ビルド コマンド | **空のまま** |
| ビルド出力ディレクトリ | **`web`** |
| ルート ディレクトリ | 空のまま |

- **なぜビルドコマンドが空か:** 変換するものが無い（素のHTMLとJavaScriptをそのまま配る）
- **なぜ出力ディレクトリが `web` か:** `web/` の中身だけを公開する。
  **空や `/` にするとリポジトリ全体が公開対象になる**

**3. 環境変数を登録する**（プロジェクト作成後、Settings → Environment variables）

| 名前 | 値 | どこから |
|---|---|---|
| `DATABASE_URL` | Neon の接続文字列 | Neon のダッシュボード |
| `GITHUB_TOKEN` | 手順1で作ったトークン | 手元に控えたもの |
| `VAPID_PUBLIC_KEY` | 通知の公開鍵 | `~/vapid/GitHubに登録する値.txt` の3つ目 |

- **なぜここに置くか:** これらは画面のJavaScriptからは読めない場所にある。
  ブラウザに配られるものは全部見えると考える

**4. Cloudflare Access で鍵をかける**
- Settings → General → Access Policy → enable
- 自分のGoogleアカウントのメールアドレスだけを許可する
- **なぜ:** これをしないと、URLを知っている人は誰でも保有と収支を見られる

**5. 効いているか確かめる（必ずやること）**
- iPhoneでURLを開く → Googleでログイン → 画面が出る
- **Safariのシークレットタブで同じURLを開く → 弾かれること**
- **弾かれなければ、そのURLは世界中の誰でも見られます。** 必ず試すこと

**6. ホーム画面に追加する**
- 共有ボタン（□に↑）→「ホーム画面に追加」
- **なぜ:** iPhoneは、ホーム画面に追加したアイコンから開いた場合のみ通知が届く。
  タブで開いているだけでは届かない（Appleの仕様で回避できない）

**7. 通知を許可する**
- ホーム画面のアイコンから開く（**タブからではない**）
- 「通知を受け取る」を押して許可する
