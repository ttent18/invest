# Discord セットアップ手順

このシステムは Discord を通じて通知を送り、あなたのボタン操作を受け取る。
その準備を行う。**所要 20〜30分。1回だけ。**

## 用語

| 用語 | 意味 |
|---|---|
| サーバー | Discord上の「自分の部屋」。今回は自分1人しか入らない |
| チャンネル | サーバーの中の「話題ごとの部屋」。`#signals` など |
| Bot | 自動で動くプログラム。今回自分で作る |
| トークン | Botのパスワード。**これが漏れるとBotを乗っ取られる** |
| Developer Portal | Botを作るためのDiscord公式サイト |

---

## Part 1: サーバーとチャンネルを作る

スマホでもPCでもよい。

1. Discordのアカウントを作る（既にあれば飛ばす） → https://discord.com
2. 左サイドバーの **「＋」（サーバーを追加）** を押す
3. **「オリジナルの作成」→「自分と友達のため」** を選ぶ
4. サーバー名を決める（例: `投資`）
5. サーバーの中に、チャンネルを2つ作る

| チャンネル名 | 用途 | 通知 |
|---|---|---|
| `signals` | 売買提案、約定の記録、毎朝の答え合わせ | **ON** |
| `journal` | 判断の全文、詳しい記録 | **OFF** |

6. `journal` チャンネルを右クリック（スマホは長押し）→ **通知設定 → なし**

> `journal` を黙らせておくのが重要。全部鳴ると、本当に大事な通知が埋もれる。

---

## Part 2: Botを作る

**PCのブラウザで行う。** スマホだと操作しづらい。

1. https://discord.com/developers/applications を開く
2. 右上の **「New Application」** を押す
3. 名前を入れる（例: `investment-bot`）。利用規約に同意して **Create**
4. 左メニューの **「Bot」** を開く
5. **「Reset Token」** を押してトークンを表示し、**すぐコピーする**

> **トークンは一度しか表示されない。** 閉じたらもう一度 Reset Token を押して作り直す。
> **絶対にやってはいけないこと**: SNSに貼る、スクリーンショットを撮る、
> チャットに貼り付ける、コードに直接書く。この後 `.env` ファイルに保存する。

6. 同じ「Bot」画面の下のほうにある **Privileged Gateway Intents** は、
   **3つとも OFF のままでよい**（Presence / Server Members / Message Content）

> これらは「他人のメッセージを読む」ような特別な権限。
> 今回はスラッシュコマンドとボタンしか使わないので不要。ONにすると
> かえって審査が必要になる場合がある。

---

## Part 3: Botを自分のサーバーに招待する

1. 左メニューの **「OAuth2」** → **「URL Generator」** を開く
2. **SCOPES** で以下2つにチェック

- [x] `bot`
- [x] `applications.commands`

3. 下に出てくる **BOT PERMISSIONS** で以下にチェック

- [x] Send Messages（メッセージを送る）
- [x] Embed Links（見やすい枠付きメッセージを送る）
- [x] Read Message History（過去のメッセージを読む）
- [x] Attach Files（ファイルを添付する）

4. 一番下の **GENERATED URL** をコピーし、ブラウザで開く
5. Part 1 で作ったサーバーを選んで **「認証」**
6. サーバーのメンバー一覧に Bot が現れれば成功（この時点ではまだ動かない。オフライン表示でよい）

---

## Part 4: IDを調べる

プログラムがどのチャンネルに送るかを指定するために、IDが必要になる。

1. Discordの **設定（歯車）→ 詳細設定 → 開発者モード** を **ON**
2. サーバー名を右クリック → **「サーバーIDをコピー」**
3. `signals` チャンネルを右クリック → **「チャンネルIDをコピー」**
4. `journal` チャンネルも同様

IDは18〜19桁の数字。

---

## Part 5: 設定ファイルに保存する

プロジェクトのルートに `.env` というファイルを作り、以下を書く。

```
DISCORD_BOT_TOKEN=ここにPart2でコピーしたトークン
DISCORD_GUILD_ID=ここにサーバーID
DISCORD_CHANNEL_SIGNALS=ここにsignalsのチャンネルID
DISCORD_CHANNEL_JOURNAL=ここにjournalのチャンネルID
```

> `.env` は `.gitignore` に登録済みなので、Gitにコミットされず外に出ない。
> このファイルは他人に見せないこと。

---

## Part 6: スマホの通知設定

1. スマホに Discord アプリを入れる
2. 作ったサーバーを開く
3. `signals` チャンネルの通知が **ON** になっていることを確認
4. `journal` チャンネルの通知が **OFF** になっていることを確認
5. スマホのOS設定で、Discordの通知が許可されていることを確認

---

## Part 7: 動作確認

実装後に、以下で確認する。

1. Windows で Bot を起動する
2. Discordでサーバーを見て、Botが **オンライン**（緑）になっている
3. `signals` チャンネルで `/ping` と打つ → 応答が返る
4. スマホに通知が届く

---

## つまずいたら

| 症状 | 原因と対処 |
|---|---|
| Botがオフラインのまま | トークンが違う。`.env` を確認。それでもダメならトークンを作り直す |
| スラッシュコマンドが出てこない | `applications.commands` のチェックを忘れている。Part 3 をやり直して招待し直す |
| Botはいるがメッセージを送れない | チャンネルの権限。サーバー設定 → 連携サービス、またはチャンネルの権限設定を確認 |
| トークンを漏らしてしまった | **すぐに Developer Portal で「Reset Token」** を押す。古いトークンは無効になる |

---

## 補足

この手順は 2026年9月時点の Discord Developer Portal の画面に基づく。
**画面の文言やボタンの位置が違っていたら、そのまま進めずに知らせてほしい。**
Discordは画面構成をときどき変更する。
